# 🚀 Gemini API Android Starter Kit (Jetpack Compose + Kotlin)

A clean, minimal, production-ready sample Android app demonstrating how to integrate Google's **Gemini API** using Kotlin Coroutines and Jetpack Compose.

Built to help Android developers rapidly add multimodal AI features to their mobile applications.

---

## ✨ Features

- **Jetpack Compose UI:** 100% declarative UI built with Material3 components.
- **Asynchronous Execution:** Kotlin Coroutines & `viewModelScope` / `rememberCoroutineScope` for smooth UI rendering.
- **Failover Logic:** Robust exception handling for network, rate limiting, and model availability.
- **Minimal Dependencies:** Built on the official Google GenAI SDK (`com.google.ai.client.generativeai`).

---
